## একটা পরিবর্তন কীভাবে লাইভ হয়

1. **Draft (খসড়া):** লিখে **Save** চাপুন। এখনো কেউ দেখতে পাবে না।
2. **In review:** রেডি হলে কার্ডটা "In review"-তে সরান।
3. **Ready:** "Ready"-তে সরান। সাইট নিজে থেকে পরীক্ষা হয়, যাতে কোনো ভুল সাইট ভেঙে না দেয়।
4. **Publish:** চাপলে কয়েক মিনিট পরেই লাইভ সাইটে দেখা যাবে।

## কিছু দরকারি কথা

- **Hidden (draft)** চালু রাখলে জিনিসটা সাইটে দেখা যাবে না।
- **Example content** হলো নমুনা। আসল লেখা বসানোর পর এটা বন্ধ করে দিন।
- **লিরিক্স সময় মিলিয়ে লিখতে** প্রতিটা লাইনের আগে সময় দিন, যেমন: `[00:12.50] প্রথম লাইন`
- **কিছুই হারায় না:** প্রতিটা পরিবর্তন ইতিহাসে জমা থাকে, চাইলে ফেরত আনা যায়।

## প্রথমবার সেটআপ (Owner একবার করবেন)

বিস্তারিত ধাপ README-তে আছে ("Dashboard, Owner and Admin")। সংক্ষেপে:

1. GitHub-এ একটা **OAuth App** বানানো (সাইন-ইনের জন্য)।
2. VPS-এ `bash /root/oauth.sh` চালিয়ে GitHub থেকে পাওয়া দুটো কোড বসানো (চ্যাটে না)।
3. GitHub-এ `main` branch-এর **protection rule** চালু করা। এতেই Owner আর Admin-এর ক্ষমতা আলাদা হয়।
   (private repo হলে GitHub-এর পেইড প্ল্যান লাগে, নইলে repo public করতে হবে।)
4. Admin-কে GitHub-এ **Collaborator (Write)** হিসেবে যোগ করা।
5. VPS সেটআপ স্ক্রিপ্ট যে দুটো তথ্য (`VPS_HOST`, `VPS_SSH_KEY`) দেখাবে, সেগুলো GitHub Secrets-এ বসানো। এরপর পাবলিশ করলেই সাইট নিজে থেকে আপডেট হবে।
