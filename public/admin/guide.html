How a change goes live

DraftWrite or edit in the dashboard and press Save. Nothing is public yet.
In reviewMove the card to In review when it's ready for a second look.
ReadyMove it to Ready. The site is test-built automatically to catch mistakes.
PublishPress Publish. A few minutes later it's live on cliffordwaldman.com.

খসড়া → রিভিউ → রেডি → পাবলিশ। পাবলিশ করার কয়েক মিনিট পরেই লাইভ সাইটে দেখা যাবে।

Good to know

  • Hidden (draft) switch: keeps an entry off the site even after publishing.
  • Example content switch: the sample entries that came with the site. Turn it off once the entry holds real content.
  • Synced lyrics: put the time before each line, like [00:12.50] First line.
  • Nothing is ever lost: every change is saved in the site's history and can be undone.

Setting up the team (Owner, once)

Access is managed with free GitHub accounts. The Owner owns the site's GitHub repository; each Admin is added as a collaborator. The full step-by-step setup is in the project README, under “Dashboard, Owner and Admin”.
